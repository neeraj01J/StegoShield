# StegoShield 🔐

StegoShield is a simple web-based image steganography application built with Python and Flask. It allows users to hide secret text inside an image and extract the hidden message later.

## Features

- Hide secret text inside an image
- Extract hidden messages from images
- LSB-based image steganography
- Simple and professional web interface
- Processing animation
- Character counter for secret messages
- Supports common image formats
- Runs locally using Flask

## Technologies Used

- Python
- Flask
- Pillow
- HTML5
- CSS3
- JavaScript
- LSB (Least Significant Bit) Steganography
